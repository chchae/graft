source/test baseline as well as this refinement. Commit units are: existing
validated workflow source/tests and prior refactors; baseline expectation fixes;

feature dependencies needed by the current refactors, and is identified as such.

manifest/result, .DS_Store or other production artifact is staged. Runtime bytes
are unchanged from this task's starting tree. The complete final Git export is
verified separately and matched against working-tree source/tests before push.
